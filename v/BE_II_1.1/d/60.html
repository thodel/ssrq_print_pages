6Anno 1668 jahrs ist durch beyde Wg. Hh. Hh. statthalter Salomon 7Martig und landsvenner Barthlome Im Oberstäg der landschaft Ober- 8Simmenthal dem jewesenden (rever) wasenmeister von dem unnütz 9abgangenen vyeh der lohn bestimmt wie folget: 10Erstlichen von einem alten pferdt an pfn. … 1 guldin 112. Von einem jährigen oder jüngeren pferdt … 1 „ 123. Von einer kuhe … VII bazen 134. Von einer zeitkuhe … VIII „ 145. Von einem meschrind … VI „ 156. Von einem kalb das abgesäugt … III „ 167. Von einem saugenden kalb, item auch von geiss 17und schafen insgemein durchs ganze jahr … II „ 18Winterszeit im grund: 191. Von einem alten pferdt an pfn. … VI bazen 202. Von jungen pferdten … VI „ 213. Von einer kuhe … VIII „ 224. Von einer zeitkuhe … VI „ 235. Von einem meschrind … III „ 246. Von einem kalb das nit mehr saugt … II1/2 „ 25Die vorstehenden 7 stuck ist sommerszeit zu vorstehen in weid 26und bergen, allwegen von mitten Meyen an bis auf Gallentag zu 27rechnen. 28Den 23 November 1675 ist durch ein ehrendes gericht zu Zwey- 29simmen abgeraten und erkannt: „Dass ein jewesender wasenmeister 30die beylen vom läder demjenigen, so das pfennwährt abgangen, innert 31monatsfrist anbieten solle.“ 32L. 1700 pag. 493.
