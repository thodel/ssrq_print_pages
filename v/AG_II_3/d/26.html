18Item man git einem jeden miner gnedigen heren vnderuögten in 19der herschaft Schenkenberg am dryten jar zů sant Michels tag vier 20pfund an ein kleid, sy sond aber die kleider machen; darzů hand sy 21den fürpieterlon, vnd wer sy lust brucht, git man einem ein tag funf 22schilling, fůter vnd mal. 23Dem vnderuogt in der obern herschaft Schenkenberg git man 24für sin lon jerlich drů pfund, darzů nimpt er das vogtenkorn oder die 25garben zů Dalhin. 26Item einem vnderuogt in der nideren herschaft Schenkenberg git 27man für sin lon jerlich zechen pfund, item zwey pfund vom win- 28zenden zů Viligen vnd Remigen inzesamlen, darzů nimpt er jerlich 29das vogtenkorn oder garben im Bötzberger ampt. 30Item der fůly- kalber- schaf- schwin- vnd hůner- zenden, so in 31dem kispel Reyn falt, ghört im halb, sol man vf sant Martins tag 32von wegen der herschaft geben, namlich für ein fůly vier pfennig, 33für ein kalb zwen pfennig, für ein schaf ein pfennig vnd für ein 34verlin ein pfennig; der ander halb theil ghört denen von Wygken. 35Item so hat der vnderuogt von jedem furpot ein schilling von 36denen, so im kein korn oder garben gend.
