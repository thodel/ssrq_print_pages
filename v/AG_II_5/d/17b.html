1Desselichen wo frönd lüt, die da nit im ampt gesäffen wärend, 2in dess ampts von Arburg höltzeren vnd wälden holtz hüwent ane 3vrlob eines vogtes vnd der rāthen zů Arburg, der sol das ableggen, 4für jeden stogk einem vogt geben an pfennigen iij lib. vnd dörzů 5mit den amptslüten machen vnd händlen vmb fōlichen frāfel, dass 6sy vnclaghafft figent etc. 7Item ein ampt Arburg fōllent ouch ein schloss vnd vesti Arburg 8jerlichen beholtzen mit brūnholtz nach notturfft ane eines jeden vogtes 9engeltmus. 10Item so ein vogt die bissäng vnd acher buwen wil, so fōllent die 11gemeind amptlüt ime dasselbing mit iren zugen, gschiss vnd gschir 12buwen vnd ehren ane einiche belōnung vnd widergeltmus. 13Item so ein vogt höūwet, so fōllent im die amptlüt gemeinlich 14hōwer darthūn, die im höūwend. 15Item so ein vogt māderen bedarff, so fōllent die amptlüt von 16stund an vff sin anruffen vnd begären ime dem vogt māyen; jedoch 17so sol ein vogt einem jeden māder sin taglon geben noch billikeit 18ane abbruch.
24Item wass lābendiger fischen das wasser herrab geuertiget werden 25vff der Ahren, doruon gehört dem vogt zů Arburg ein gryff, dass ist 26der zolln. 27Denne wass von eglin fyschen vff dem wasser der Ahren hinab 28gadt in körben, doruon gehört dem vogt zů Arburg ein ållen 29fischen etc. 30Denne von einem büklin mit eglin gehört einem joden vogt zů 31Arburg an pfennigen iij d. 32Denne von einem ross, geladen mit zwōyen fischbüklinen, git man 33zolln einem vogt zů Arburg an pfennigen vj haller. 34Denne von einem büklin eglin fisch, die gfaltzen find, git man 35zolln einem vogt zů Arburg an pfennigen j haller.
